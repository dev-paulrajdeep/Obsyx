# Noctis Amethyst VS Code Theme

## Installation
1. Copy the `noctis-amethyst-color-theme.json` to a local VS Code extensions folder as a custom extension, or use an extension developer tool like `vsce` to package it.
2. Alternatively, open your `settings.json` and manually apply the contents of the `colors` dictionary to your `workbench.colorCustomizations` block.

## Updates
When the core Obsyx design tokens are updated, regenerate this theme file using the custom token compiler and replace your local copy.
