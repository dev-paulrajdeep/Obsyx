# Noctis Amethyst Browser Theme

Currently, browser theming is achieved via an extension like "Stylus" or by utilizing Firefox's `userChrome.css`.

## Firefox Installation (userChrome.css)
1. Open Firefox and navigate to `about:config`. Set `toolkit.legacyUserProfileCustomizations.stylesheets` to `true`.
2. Go to `about:support` and open your Profile Directory.
3. Create a folder named `chrome` if it doesn't exist.
4. Copy the contents of `userChrome.css` (when generated) into that folder.
5. Restart Firefox.
